================================================================================
  🚀 DÉMARRAGE RAPIDE (2 minutes)
================================================================================

1. COMPILER LE RAPPORT:

   Ouvrir terminal dans D:\pfa\rapport et exécuter:

   pdflatex main.tex
   pdflatex main.tex    (2 fois pour table des matières)

   → main.pdf sera généré dans le même dossier

2. MODIFIER UN CHAPITRE:

   Ouvrir n'importe quel fichier dans chapters/ avec un éditeur
   (VS Code, Notepad, etc.)

   Exemple: chapters/chapitre1.tex

   Recompiler après modification

3. AJOUTER CONTENU:

   Utiliser des commandes LaTeX standards:
   \section{...}
   \subsection{...}
   \begin{itemize} ... \end{itemize}
   \begin{tabular} ... \end{tabular}

================================================================================
  ⚙️ INSTALLATION PRÉALABLE (si nécessaire)
================================================================================

Si vous n'avez pas LaTeX installé:

Windows:
  - Installer MiKTeX (https://miktex.org/download)
  - Ou TexLive (https://tug.org/texlive/)
  - Ou utiliser Overleaf en ligne (https://www.overleaf.com)

Linux/Ubuntu:
  sudo apt install texlive-full

macOS:
  brew install mactex

Une fois installé, pdflatex sera disponible en terminal
